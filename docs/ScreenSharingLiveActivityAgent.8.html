NAME

ScreenSharingLiveActivityAgent — Screen Sharing Live Activity Agent

DESCRIPTION

ScreenSharingLiveActivityAgent indicates to the current user through one or more Live Activities that the screen is being observed by one or more screen sharing features.

The ScreenSharingLiveActivityAgent command should not be run directly.
