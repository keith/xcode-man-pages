APPLEDEPTHD(8) System Manager's Manual APPLEDEPTHD(8)

NAME

appledepthd — Depth estimation system management.

SYNOPSIS

takes no arguments, and users should not launch it manually.

DESCRIPTION

facilitates on-demand depth estimation management activities, like downloading additional resources.

HISTORY

appledepthd first appeared in macOS 27.1.
